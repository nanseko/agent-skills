# Data Source Catalog

This catalog defines the initial external datasets for an economic and housing data ingestion layer. Every collector must preserve the upstream raw response, attach a collection timestamp, and store source metadata with each snapshot before any normalized tables are produced.

## Global ingestion requirements

- **Raw-first storage:** persist the exact upstream payload in a versioned raw snapshot path before transformation.
- **Metadata envelope:** record `source_name`, `source_url`, request parameters, response format, collector version, collection timestamp in UTC, upstream release or observation timestamp when available, checksum, license/terms URL, and target table/path.
- **Secrets policy:** API keys and tokens must be read from environment variables only. Do not commit credentials, `.env` files with values, or generated artifacts containing secrets.
- **Reproducibility:** normalized records should retain a pointer to the raw snapshot path and checksum.
- **Cadence policy:** schedule collectors at or above the upstream release cadence, but make runs idempotent by source series/date/version.

## Notes for implementers

- Prefer official APIs or official downloadable files over scraped pages.
- When both FRED and direct-source versions exist, keep separate raw namespaces so provenance is explicit.
- Store API request URLs with secret values redacted, for example `api_key=<redacted>`.
- Record no-key access explicitly for public endpoints. If a source supports optional registration keys, the collector must still accept only an environment variable reference, not an inline key.
